#### 管理员新增比赛数据

数据库需要保存字段：

竞赛名称	颁奖单位	获奖级别（校级、区级、国家级）	等级（优秀奖、一等奖、二等奖、三等奖、未获奖）	得分

因为不同比赛的获奖级别对应等级的评分有所不同，需要管理员在添加比赛数据时，进行指定。得分示例：

| 参与院级以上比赛： 2分/项（负责人）                        |
| ---------------------------------------------------------- |
| 院级获奖每项增加： 一等奖2分；其它等级奖 1.5分；优秀奖 1分 |
| 自治区级获奖每项增加：二等奖 5分；三等奖4分； 优秀奖3分    |

对于未获奖的比赛团队，只有其负责人可以加2分



#### 在用户提交比赛记录审核中

用户需要填写比赛分类、比赛名称、比赛的竞赛等级与获得的获奖等级、第一负责人，如果有多位人员参加，提供添加人员的按钮，参赛/获奖证明。在比赛记录审核表中，可以有冗余字段去记录参赛人员。需要有一个记录参赛人员的得分表，字段为比赛ID、人员ID、得分。

对于不同参赛人员的不同得分比例情况，只需要简单的在前端页面用一个蓝色的提示框表明就行，不需要特殊处理。得分比例示例：

| 两人完成，按7:3分配                                 | 三人完成，按6:2:2分配 |      |
| --------------------------------------------------- | --------------------- | ---- |
| 四人及以上完成，主持者分配  50%；参与者平均分配 50% |                       |      |

审核记录是由团队中的负责人来填写，但是审核记录是可以共享给对应比赛的团队成员的。

在比赛记录界面可以添加一个展示当前用户所得的所有分数区域；
